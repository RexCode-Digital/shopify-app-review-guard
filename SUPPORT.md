# Support

Use [GitHub Issues](https://github.com/RexCode-Digital/shopify-app-review-guard/issues) for reproducible bugs, documentation problems, and focused feature requests. Include the Shopify App Review Guard version, command or Action configuration, Node.js/npm and operating system versions, a minimal sanitised reproduction, and expected and actual behaviour. For framework or webhook reports include the route shape and framework version, not application secrets or production payloads.

Remove credentials, tokens, merchant/customer data, private source, private URLs, and production secrets. Do not post suspected vulnerabilities publicly; follow [SECURITY.md](SECURITY.md) for private reporting.
