# Security policy

Report suspected vulnerabilities privately through [GitHub Security Advisories](https://github.com/efegokdemir/shopify-app-review-guard/security/advisories/new). Do not include Shopify credentials, access tokens, private keys, or merchant data.

The scanner is read-only, offline by default, does not execute the scanned repository, and does not upload source. The latest published package and `main` receive security attention.
