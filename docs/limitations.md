# Limitations

Static analysis cannot prove actual Shopify Partner Dashboard configuration, App Store listing state, merchant installation behaviour, runtime latency, production billing lifecycle, Shopify approval status, protected-data approval status, all framework-specific runtime behaviour, or every custom abstraction.

`NEEDS_REVIEW` means the repository evidence is incomplete or the requirement is external. It is not a failure verdict. Run the tool alongside development-store testing, Shopify's current submission checklist, runtime security testing, and appropriate human review.
